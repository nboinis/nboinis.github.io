# nboinis.github.io

Personal academic website of **Nikolaos Boinis**, PhD candidate in Environmental Analytical Chemistry in the [TrAMS group](https://trams.chem.uoa.gr/), National and Kapodistrian University of Athens.

**Live site:** https://nboinis.github.io

Research: wide-scope target and non-target screening of organic micropollutants in soils, invertebrates and wildlife with GC-HRMS, LC-HRMS and LC-TIMS-HRMS (European project [TerraChem](https://terrachem.eu/)).

- Google Scholar: [profile](https://scholar.google.com/citations?user=UPhrzNcAAAAJ)
